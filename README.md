# ⚔️ Classe de Herói

Projeto desenvolvido em **JavaScript** para praticar conceitos fundamentais de **Programação Orientada a Objetos (POO)**, como classes, objetos, construtores, atributos e métodos.

## 📌 Sobre o projeto

O programa define uma classe chamada `Heroi`, responsável por representar personagens com nome, idade e tipo.

Cada herói possui um método `atacar()`, que determina o tipo de ataque de acordo com o tipo do personagem.

### ⚔️ Tipos de herói

| Tipo           | Ataque         |
| -------------- | -------------- |
| 🧙 `mago`      | magia          |
| ⚔️ `guerreiro` | espada         |
| 🥋 `monge`     | artes marciais |
| 🥷🏿 `ninja`     | shuriken       |

Caso seja informado um tipo não reconhecido, o programa retorna um ataque desconhecido.

## 🧠 Conceitos praticados

* Classes;

* Construtor (`constructor`);
* Atributos;
* Métodos;
* Instanciação de objetos com `new`;
* Palavra-chave `this`;

## 🛠️ Tecnologias utilizadas

* JavaScript
* Node.js

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/OlokoDri/Classe-de-her-i.git
```

Acesse a pasta do projeto:

```bash
cd Classe-de-her-i
```

Execute o arquivo JavaScript com o Node.js:

```bash
node nome_do_arquivo.js
```

> Substitua `nome_do_arquivo.js` pelo nome do arquivo principal do projeto.
